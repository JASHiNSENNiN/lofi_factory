# Impulse Response Files

Drop `.wav` or `.flac` IR files here to enable real room reverb for jazz/piano genres.

Applied genres: `lofi_jazz`, `jazz_cafe`, `piano_lofi`, `lofi_classical`, `bossa_lofi`, `neo_soul`
Mix: 40% IR wet + 60% dry (after the main pedalboard chain)

## Free IR Sources

- **EchoThief** — http://www.echothief.com/downloads/ (rooms, halls, plates)
- **OpenAIR** — https://www.openairlib.net/ (cathedrals, rooms, plates)
- **Fokke van Saane** — https://fokkie.home.xs4all.nl/IR.htm (small rooms, jazz club)

## Recommended for lofi jazz

Any small room IR (RT60 ~0.5-1.2s) or jazz club IR works well.
Avoid large halls — too washy for lofi.

If this folder is empty, the pipeline uses pedalboard's algorithmic reverb instead.
